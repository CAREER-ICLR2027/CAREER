# CAREER 方法与实现对应

本文依据本地 37 页论文稿件（SHA-256：`aea6a55d2258588808cf1bd3237bf7669f2ca54653302df7552de51eda8c2028`）的 §3.2–3.4、附录 A、C.3 和 E。这里只描述单次推理方法与代码接口。

## 1. 全图筛选与候选图谱

输入为原图 $I$、问题 $q$ 和至少两个答案选项。生成器对全图一次推理，取选项首 token logits 的 softmax 概率 $p_i$，保存最高概率选项 $y_0$。若最大概率至少为 $\tau_{\mathrm{conf}}$，且领先与次选概率差至少为 $\tau_{\mathrm{gap}}$，直接返回该选项；否则进入局部搜索。全图筛选阶段不调用独立验证器。

生成器随后仅根据问题文本规划定位短语与编号证据需求，不接收图像、选项或参考答案。SAM 3 对各短语定位；同一短语的有效检测框合并为一个最小外接框。缓存的 SAM 特征再经 SLIC/SGAP 构建层次候选树。SAM 区域与树节点按完全相同的几何框去重，仅树节点保留父子关系。**两个候选来源先合并并排序，之后才取得第一张局部视图。** 首张视图从联合图谱中最高优先级的可行候选取得，没有额外的 SAM screening 阶段。

候选 $c$ 的优先级直接使用论文式 (5) 的原始分量：

$$
R(c)=0.70S_q(c)+0.30[0.50D_f(c)+0.50D_e(c)].
$$

$S_q$ 为 CLIP 局部图像向量与“问题加定位短语”的平均归一化文本向量的余弦相似度；$D_f$ 为框内 SAM 特征相对均值方向的离散度；$D_e$ 为按长宽比缩放、填充、腐蚀有效掩码后计算的平均 Sobel 梯度模长。三个分量**不做跨候选 min–max 归一化**，见附录 C.3。排序仅是搜索优先级，不能当作验证证据。

## 2. 累计证据、导航与独立验证

证据序列 $B_t$ 始终按“全图、已取得的局部视图”顺序送入生成器和验证器。每张局部图从原图像素裁切，并附原图坐标、候选标识和来源。切换或恢复焦点时保留全部已有视图；相同几何框不重复计数。新增视图前检查生成器和验证器的输入容量。

每取得一张有效局部图，本轮按以下顺序执行：

1. 生成器用当前 $B_t$ 更新临时答案。
2. 如果预算、容量和合法动作允许，生成器根据 $B_t$ 及**此前轮次**的验证反馈提出下一动作。首轮反馈为空。提案尚不执行。
3. 独立验证器对每个选项分别运行一次，同次 completion 的首 token 给出 `A`（Support）、`B`（Refute）或 `C`（Insufficient）的 logits，随后生成引用已有视图和需求编号的 JSON 解释。验证器不接收生成器答案或其他选项。
4. 控制器先判定是否接受；未接受时检查停滞或无合法动作，必要时执行 `RECOVER`；否则执行刚才的提案。失败动作被排除后可在同一证据和反馈上重新规划。

令 $s_{t,i}=P(A\mid B_t,q,o_i)$，$\rho_{t,i}=s_{t,i}/\sum_j s_{t,j}$。若领先选项的绝对支持 $s_{t,i^*}\ge0.65$，且其相对支持份额与次选之差 $\ge0.15$，返回该选项。解释 JSON 解析失败不改变已取得的首 token 分数。

生成器可提议 `ZOOM`、`EXPAND`、`SPLIT` 或 `NEXT`。前两者保留候选标识，用 SAM 在当前框或原图定位并改变观察范围；后两者分别访问当前树节点的最高优先级可行子节点或联合图谱中的最高优先级可行未访问候选。`RECOVER` 仅由控制器执行，恢复到仍有未尝试合法观察的历史焦点，已有证据不丢失。

未被接受时，控制器比较相邻有效观察的领先绝对支持 $c_t$ 和领先相对份额 $r_t$。当 $c_t-c_{t-1}<0.01$ 且 $r_t-r_{t-1}<0.01$ 连续两步成立，或当前状态没有合法观察，触发恢复。论文没有额外要求领先选项保持不变。最多取得 8 张有效局部视图；预算、容量或可行候选耗尽时返回保存的全图答案，并标记为未验证回退。

## 3. 参数边界

论文表 S1 固定了 $w=0.70$、$\lambda=0.50$、支持阈值 $0.65$、间隔阈值 $0.15$、两个进展阈值 $0.01$、停滞耐心 2 和局部视图上限 8。附录 C.3 还给出 SGAP 的 `n_atoms=600`、`pos_weight=3.5`、`split_threshold=0.30`、`keep_threshold=0.15`、`max_depth=3`、`min_splits=4`、`max_splits=8`，并启用局部归一化和 silhouette 评分。

`RuntimeConfig` 由调用者提供。要按论文默认方法运行，必须把上述可配置字段设为论文值。论文没有给出所有运行数值，例如边缘图固定尺寸与插值、各 completion 输出 token 上限、模型上下文容量、SGAP 最小区域尺寸及节点上限；仓库要求显式配置这些值，不把它们伪称为论文默认值。具体模型权重、精度和运行环境同样影响输出。
